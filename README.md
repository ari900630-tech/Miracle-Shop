חנות Android ייעודית שמציגה ומפיצה אפליקציות של המפתח המאושר בלבד: `ari900630-tech`.

- חיפוש בראש

- משוב לחיצה
- ממשק עברית RTL

אין לשמור Service Account private key בתוך הקוד או המאגר. סודות צריכים להיות ב-GitHub Actions Secrets או Secret Manager.
